SUN LI-HENG 個人網站 第二版

開啟方式：
1. 用 VS Code 開啟資料夾
2. 用 Live Server 開 splash.html 或 index.html

後台：
login.html
帳號：admin
密碼：1234

本版功能：
- 多頁式網站：首頁、藝術家自述、作品系列、媒介實驗、展覽紀錄、工作室筆記、聯絡
- splash.html 開場動畫頁，可把影片放在 videos/intro.mp4
- 導覽列 hover 互動
- 後台只保留作品管理與權限管理
- 已儲存作品可編輯、自由版面、刪除
- 作品編輯直接進入 visual-editor.html
- 可拖曳、縮放、旋轉、顯示角度
- 可調文字顏色、大小
- 作品頁 work-detail.html 會優先顯示自由版面
- 資料使用 localStorage 模擬 CMS


第三版新增：
- 登入狀態使用 localStorage 保持，切換頁面和重新整理後仍登入。
- 登入後每個公開頁面底部中央會出現「編輯」按鈕。
- 點「編輯」後可直接在該頁調整文字、圖片、按鈕與卡片：
  1. 點文字可直接修改內容。
  2. 點圖片可拖曳、縮放、旋轉；按「換圖片」可替換圖片。
  3. 點按鈕或文字可改顏色、字級、拖曳、縮放、旋轉。
  4. 旋轉接近 0 / 90 / 180 / 270 / 360 度會自動吸附。
  5. 按「儲存頁面」會把該頁修改存在 localStorage。
- 此功能參考網站後台修改分級概念：圖文內容適合開後台修改；頁面結構與系統邏輯仍建議由工程端維護。


第四版修正：
- 未輸入帳號密碼不會進入登入狀態。
- login.html 會顯示帳號/密碼輸入介面。
- 登入後導覽列會顯示「後台」與「登出」。
- admin.html 補上登出按鈕。
- 公開頁面登入後才會顯示底部「編輯」按鈕。
- 編輯模式新增：
  放置文字、放置圖片、放置按鈕、顏色、背景、字級、旋轉。
- 「放置」會新增可拖曳/縮放/旋轉的方塊。
- 圖片可替換，新增圖片會從本機選檔。
- 登出後公開頁面不再顯示編輯按鈕。
