GitHub 同步

把目前在瀏覽器編輯的作品、網站設定與版面資料，同步到 GitHub 的 data/site-data.json。

Token 怎麼設定？

GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token。

Repository access 選你的網站 repo，Permissions 只開 Contents: Read and write。

Token 不會寫進網站檔案，只會存在你這台電腦的瀏覽器 localStorage。
